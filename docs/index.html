E About the Data

This interactive tool visualizes the U.S. domestic flight network using a snapshot from the public OpenFlights Database (frozen around 2014) under the Open Database License. Nodes represent U.S. domestic airports with valid IATA codes, and undirected edges represent direct non-stop commercial flights.
